# AI/ML Contribution Practice

This companion guide gives newcomers a concise path through the AI/ML resources in this repository.

## Suggested learning order

1. **Python & data science:** Python, NumPy, Pandas, Matplotlib, and basic statistics.
2. **Machine learning:** supervised learning, unsupervised learning, preprocessing, and model evaluation with scikit-learn.
3. **Deep learning:** neural networks, activation functions, loss functions, optimizers, and training/validation.
4. **Applied AI:** choose a computer vision or NLP project and evaluate the results.
5. **Deployment:** expose a trained model through FastAPI, Flask, or Streamlit.

## Beginner project ideas

- House price prediction
- Spam detection
- Sentiment analysis
- Image classification
- Recommendation system
